# Data

`logistics_sample_data.csv` is a synthetic logistics dataset created for the Week 1 technical demonstration.

It contains 250 shipment records with:

- shipment_id
- shipment_volume
- distance_km
- transport_cost
- warehouse_load_pct
- weather_risk
- traffic_index
- shipping_mode
- delivery_days
- on_time

This file is not proprietary data and should not be represented as real company operational data.
